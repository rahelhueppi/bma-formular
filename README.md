# Umfrageplattform – Virale Kurzvideos

Diese Webanwendung wurde im Rahmen unserer Berufsmaturitätsarbeit (BMA) entwickelt. Ziel der Umfrage ist es, herauszufinden, ob Personen virale TikTok-Videos in einem Blindvergleich häufiger erkennen als nicht-virale Videos.

## Funktionen
- Vergleich von 10 Videopaaren
- Auswahl des bevorzugten Videos pro Paar
- Speicherung der Umfrageantworten in einer Datenbank
- Export der Ergebnisse als CSV-Datei

## Technologien
- **Backend:** Node.js mit Express
- **Datenbank:** Supabase
- **Hosting:** Render
